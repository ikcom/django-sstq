Task Definition
===============

This section describes how to design tasks and structure task modules.

Functions
---------

Function-based tasks are a good default for stateless background jobs.

Methods
-------

Method-based tasks are useful when task logic is tightly coupled to an object
or model.

Task Scheduling
---------------

Document the scheduling behavior and queue semantics your deployment uses.

Discovery
---------

Document where task modules live and how import/discovery happens during app
startup.
