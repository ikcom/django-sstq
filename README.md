# django-sstq

*/ˈdʒæŋɡoʊ-stɪk/*

Super Simple Task Queue - a django app that provides a
simple way to run background tasks in your Django project.

# Acknowledgements and Attribution

SSTQ is heavily inspired by Django's Tasks framework and
`RealOrangeOne/django-tasks <https://github.com/RealOrangeOne/django-tasks>`_.
Some code in this repository is adapted from those projects.

Third-party attribution and license texts are available in
``THIRD_PARTY_LICENSES``.
